## 📜 Description

**Rediscovered Loot Fix** is a mod for *Single Player Tarkov* that fixes searched items staying unsearched.

Once you have found an item, the game only updates the loot window the first time you find it.
If a bot or teammate moves it somewhere else and you search it again, it stays unsearched and you can't drag or open it until you close and reopen the container.

For example: you loot a scav and leave their mags, a bot loots them, you kill that bot and search his rig. The mags stay unsearched.
In co-op, the same happens when a teammate moves an item in a container you both searched and you search it again.

## 📁 Installation

* Download the latest release
* Copy the `BepInEx` folder into your SPT folder
* Start the game
